# Hospital Aurora — Recrutamento

Portal de estudo do Hospital Aurora.

## Publicar no GitHub Pages

1. Envie todos os arquivos deste pacote para o repositório `Hospital-Aurora-Recrutamento`.
2. No GitHub, abra **Settings → Pages**.
3. Em **Build and deployment**, selecione **Deploy from a branch**.
4. Escolha a branch `main` e a pasta `/ (root)`.
5. Salve e aguarde o GitHub Pages publicar o site.

O arquivo `index.html` é a página inicial. A logo está em `assets/logo-hospital-aurora.png`.

> A prova oral não está incluída no site público; o conteúdo é apresentado como guia de estudo.
